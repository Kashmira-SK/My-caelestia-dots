# Lucide sidebar controls

Small SVG subset of [Lucide](https://github.com/lucide-icons/lucide): copy,
ellipsis, chevron-down, x, check, list-x, message-circle, wifi, smartphone,
globe, and bell. Utilities also use coffee, video, play, pause, square, bluetooth,
mic, settings, gamepad-2, bell-off, key-round, list-video, folder, and trash-2.
See LICENSE for Lucide and Feather notices.

Used by the notification sidebar and utilities. SVG stroke geometry uses
currentColor; the QML components apply the existing live Colours palette through
ColouredIcon. Utility buttons inherit their original active/inactive colors.
Notification headers use outline category icons instead of sender-provided logos.
Chat notifications (including WhatsApp relayed by Firefox or KDE Connect) use a
message bubble; network, phone, browser, and other notifications use matching
category glyphs. Icons elsewhere in the shell are unchanged.
