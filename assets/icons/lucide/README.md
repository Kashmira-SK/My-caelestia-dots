# Lucide notification controls

Small SVG subset of [Lucide](https://github.com/lucide-icons/lucide): copy,
ellipsis, chevron-down, x, and check. See LICENSE for Lucide and Feather notices.

Used only by the notification sidebar. SVG stroke geometry uses currentColor;
NotifToolButton.qml applies the existing live Colours palette through ColouredIcon.
Sender-provided app logos and icons elsewhere in the shell are unchanged.
